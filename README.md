# 🧠 MathRush

A simple and fun mental math game built with HTML, CSS and JavaScript.

Solve random math questions, increase your steps, and try to beat your record!

## ✨ Features

- Random math questions
- Addition, subtraction, multiplication and division
- Calculator buttons
- Keyboard support
- Correct and wrong answer sounds
- Sound on/off
- Step counter
- Personal record saved with LocalStorage
- Responsive design

## 🎮 How To Play

1. Click START
2. Solve the math question
3. Enter your answer using the calculator or keyboard
4. Press OK or Enter
5. Try to get the highest Step possible!

## 🔊 Sound

You can turn the game sounds on or off using the volume button.

Your sound setting is saved in LocalStorage.
